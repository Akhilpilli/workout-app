# Workout App

A mobile-friendly strength workout log based on the Half Marathon + Abs plan.

## Run locally

Open `index.html` in a browser. Workout history is stored in that browser's local storage. Use the app's JSON export regularly to keep a portable backup.

## Publish with GitHub Pages

1. Create a public repository named `workout-app`.
2. Push this repository's `main` branch to GitHub.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. The project site will be published at `https://<username>.github.io/workout-app/`.

The repository and plan are public. Workout logs stay in each browser and are not committed to this repository.
